Folder ini diisi oleh:  python3 tools/gen_events.py   (mengambil event published dari Supabase -> events.json)
Lalu jalankan:          python3 tools/build.py        (membuat id/e/*.html, en/e/*.html, dan sitemap)
Ulangi tiap kali menambah event, lalu git add -A && git commit && git push.

BLOG
  1. Jalankan supabase/schema_blog.sql di Supabase SQL Editor (sekali).
  2. Tulis di Panel Admin > Blog (maks 4000 karakter, mode Teks atau HTML). Klik Terbitkan.
  3. python3 tools/gen_blog.py && python3 tools/build.py  -> membuat blog/<kategori>/<alamat>.html (atau tunggu workflow "Sinkron konten" tiap 3 jam).
  Folder blog/ adalah hasil build: jangan diedit tangan.
